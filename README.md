The official Terraform provider for Magalu Cloud, allowing you to manage your cloud infrastructure as code. As an official HashiCorp Partner, this provider follows Terraform best practices for reliability and user experience.

## Provider Features

The MGC provider gives you comprehensive control over your Magalu Cloud resources, including:

### Networking

- **Virtual Private Clouds (VPCs)** - Create isolated network environments
- **Subnets** - Segment your VPC networks
- **Security Rules** - Control traffic with fine-grained permissions
- **Public IPs** - Expose services to the internet

### Compute

- **Virtual Machines** - Deploy and manage instances with various sizes and configurations
- **VM Snapshots** - Create point-in-time backups of your instances
- **SSH Keys** - Securely access your virtual machines

### Kubernetes

- **Managed Kubernetes Clusters** - Deploy production-ready Kubernetes
- **Node Pools** - Scale your Kubernetes worker nodes

### Database as a Service (DBaaS)

- **Database Instances** - Deploy managed database services
- **Replication** - Configure high availability and read replicas

### Storage

- **Block Storage** - Persistent volumes for your instances
- **Volume Snapshots** - Point-in-time backups
- **VM Volume Attachment** - Connect storage to your virtual machines
- **Object Storage** - S3-compatible storage for unstructured data

## Usage Example

```hcl
terraform {
  required_providers {
    mgc = {
      source = "magalucloud/mgc"
    }
  }
}

provider "mgc" {
  region  = "br-ne1"
  api_key = var.api_key
}

variable "api_key" {
  type      = string
  sensitive = true
}

# Create a virtual machine instance
resource "mgc_virtual_machine_instances" "example_vm" {
  name              = "example-vm"
  machine_type      = "BV1-1-40"
  image             = "cloud-ubuntu-24.04 LTS"
  ssh_key_name      = "my-ssh-key"
}
```

## Releases and Versioning

The provider follows [semantic versioning](https://semver.org/) practices. You can find all releases, including pre-releases, release notes, and binaries at our [GitHub Releases page](https://github.com/MagaluCloud/terraform-provider-mgc/releases).

When specifying the provider version in your Terraform configurations, we recommend using version constraints to ensure compatibility:

```hcl
terraform {
  required_providers {
    mgc = {
      source  = "magalucloud/mgc"
      version = "~> 0.32.0"
    }
  }
}
```

## Local Development

### Building the Provider

1. Clone the repository
2. Install dependencies

- Install [Go](https://golang.org/dl/) (version 1.26.3 or higher)
- Install [GoReleaser](https://goreleaser.com/)
- Install [Terraform](https://www.terraform.io/downloads)
- Install [Make](https://www.gnu.org/software/make/)
- Install [Git](https://git-scm.com/downloads)

3. Run `make build` to build the provider locally

```bash
# Clone the repo
git clone https://github.com/MagaluCloud/terraform-provider-mgc.git
cd terraform-provider-mgc

# Build the provider
make build
```

### Testing

Before submitting contributions, please run:

```bash
# Run pre-commit checks
make before-commit

# Run all tests
make go-test
```

### Commands JSON Generator

The file `commands.json` at the root of the repository is generated by `scripts/gen_commands_json.go`. It maps every resource and data source to its Terraform example, schema attributes, and import command. This file is used in the Magalu Cloud documentation to generate the attribute description table for each resource.

To regenerate it, run:

```bash
make gen-commands-json
```

Or directly from the `scripts/` directory:

```bash
cd scripts
go run gen_commands_json.go
```

To enable automatic translation of descriptions to Portuguese (PT-BR), set `DEEPL_API_KEY` in a `.env` file at the repository root before running the script. Without the key, existing translations are preserved and only new or changed descriptions will remain in English.

#### JSON Structure

The file is an object whose keys identify each resource or data source in the format `resource.<name>` or `datasource.<name>` (e.g. `resource.virtual_machine_instances`). Each entry contains:

```json
"resource.virtual_machine_instances": {
  "command": "resource \"mgc_virtual_machine_instances\" \"example\" {\n  ...\n}",
  "attributes": [
    {
      "name": "name",
      "description": "Nome da instância",
      "original_description": "Name of the instance",
      "type": "string",
      "required": true,
      "read_only": false,
      "default_value": null
    },
    {
      "name": "interfaces",
      "description": "Interfaces de rede anexadas à instância",
      "original_description": "Network interfaces attached to the instance",
      "type": "array(object)",
      "required": false,
      "read_only": true,
      "default_value": null,
      "nested_attributes": [
        {
          "name": "id",
          "description": "ID da interface",
          "original_description": "Interface ID",
          "type": "string",
          "required": false,
          "read_only": true,
          "default_value": null
        }
      ]
    }
  ],
  "import": "terraform import mgc_virtual_machine_instances.example <id>"
}
```

| Field | Description |
|---|---|
| `command` | Terraform example block extracted from the resource documentation |
| `attributes[].name` | Attribute name as used in the Terraform configuration |
| `attributes[].description` | Description in Portuguese. Translated automatically via DeepL when `DEEPL_API_KEY` is set; falls back to the original English text otherwise |
| `attributes[].original_description` | Original English description extracted from the documentation |
| `attributes[].type` | Type of the attribute (`string`, `number`, `bool`, `object`, `array(object)`, `map(string)`, etc.) |
| `attributes[].required` | Whether the attribute is required |
| `attributes[].read_only` | Whether the attribute is read-only (computed) |
| `attributes[].default_value` | Default value of the attribute, or `null` if none |
| `attributes[].nested_attributes` | Nested attributes for `object` and `array(object)` types, following the same structure recursively |
| `import` | Terraform import command for the resource, when available |
